# دكتوري ⚕️

مساعد طبي ذكي للطبيب العام: تشخيص تفريقي بالذكاء الاصطناعي، قراءة التحاليل والصور، وكتابة وصفة PDF بترويسة الطبيب.

- **لا يحفظ أي بيانات للمرضى** — كل شي ينمسح عند "مريض جديد".
- يحفظ على الموبايل فقط: معلومات الطبيب، القوالب، الأدوية المضافة، ومفتاح الذكاء الاصطناعي.
- قاعدة أدوية شائعة بالسوق العراقي مع حساب جرعات الأطفال حسب الوزن.
- تنبيهات: الحساسية، الحمل، العمر، التداخلات الدوائية، تكرار الصنف.

## التحميل
- **أندرويد:** من قسم Releases حمّل `doctori.apk`.
- **آيفون / كمبيوتر:** نسخة الويب من GitHub Pages (مجلد `docs`).
